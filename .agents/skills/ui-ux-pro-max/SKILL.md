# UI/UX Pro Max: Pull components from 21st.dev

## The Fun Part
21st.dev is a library of ready-made React sections — heroes, navbars, pricing tables, testimonials. Each one has a Copy prompt button.

- **Find a component you like** → click **Copy prompt** → paste it into Claude Code / Antigravity.
- **Add one line of your own**: "Add this as the hero section and use my brand colours."
- **Build one section at a time**: navbar → hero → features → testimonials → pricing → footer.
- **Look at the browser after each one** and tell the agent what to change. That back-and-forth is the workflow.

## Best Practices
1. **Motion & Transitions**: Leverage `motion` for fluid entrances, hover effects, and layout animations.
2. **Design Cohesion**: Maintain a harmonious color palette, typography, and spacing system across all imported sections.
3. **Modular Structure**: Keep components organized cleanly in `src/components/`.
4. **Iterative Polish**: Test in the browser after adding each section to refine styling and responsiveness.
